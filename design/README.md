# Design skills

Skills for anything with a screen: demos, PoCs, internal tools, client prototypes, dashboards, landing pages, and HTML reports.

- [`coxit-design`](coxit-design/SKILL.md) — COXIT's design system and UI/UX standard: tokens (CSS, Tailwind v3/v4, shadcn), components derived from coxit.co, UX rules for B2B and AI products, a copy guide, a restyle workflow, and a review checklist.

See the [repository README](../README.md) for how to load a skill in Claude.ai or Claude Code. For a front-end repo, the team path from [engineering/README.md](../engineering/README.md) works well: copy the skill into the project's `.claude/skills/` so everyone building that UI gets it automatically.
